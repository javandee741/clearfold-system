# Clearfold — 이기종 Capability 컴퓨팅 시스템

**Computation, not Process.**

Clearfold는 capability-based 마이크로커널을 기반으로 하는 연구 단계의 운영·컴퓨팅 시스템입니다. Process와 File을 커널의 중심 개념으로 두지 않고, 명시적 authority, user-space service, 그리고 상위 수준의 Computation 모델을 중심으로 설계합니다. CPU는 GPU, QPU, 자기/삼진, 뉴로모픽 및 미래의 물리 컴퓨팅 backend 중 하나입니다.

현재 v0.1–v0.15 아키텍처 baseline이 완성되었으며 첫 x86-64/UEFI Prototype P0 구현이 다음 단계입니다.
