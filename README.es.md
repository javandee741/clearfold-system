# Clearfold — Sistema de computación heterogénea basado en capabilities

**Computation, not Process.**

Clearfold es un sistema operativo y de computación experimental basado en un microkernel de capabilities. El núcleo no gira alrededor de Process, File ni de una CPU concreta: la autoridad explícita, los servicios en espacio de usuario y el modelo de alto nivel **Computation** son los elementos fundamentales. CPU, GPU, QPU, hardware magnético/ternario, neuromórfico y futuros aceleradores pueden actuar como backends.

La arquitectura v0.1–v0.15 está definida; el siguiente paso es implementar el primer Prototype P0 para x86-64/UEFI.
