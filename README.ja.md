# Clearfold — ヘテロジニアス Capability Computing System

**Computation, not Process.**

Clearfold は capability-based マイクロカーネルを基盤とする研究中の OS / computing system です。Process や File をカーネルの中心に置かず、明示的な authority、user-space services、そして高水準の Computation モデルを中心に設計します。CPU は GPU、QPU、磁気/三値、ニューロモーフィック、将来の物理計算装置と並ぶ backend の一つです。

現在は v0.1–v0.15 のアーキテクチャ baseline が完成しており、最初の x86-64/UEFI Prototype P0 はこれから実装します。
