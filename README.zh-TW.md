# Clearfold — 異質 Capability 計算系統

**Computation, not Process.**

Clearfold 是一個研究中的 capability-based 微核心作業與計算系統。核心不以 Process、File 或特定 CPU 為中心，而以權限明確的 kernel objects、user-space services 與高階 Computation 模型組合整個系統。CPU、GPU、QPU、磁性/三進位、神經形態與未來加速器都可成為計算 backend。

目前完成的是 v0.1–v0.15 架構基線；第一個 x86-64/UEFI Prototype P0 尚待實作。

完整技術文件優先語言：English、Русский、简体中文。繁體中文先維護專案首頁與高價值文件，並預留完整翻譯結構。
