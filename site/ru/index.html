Clearfold

Computation, not Process. Малое capability-микроядро, user-space граф сервисов и runtime, который может размещать вычисления между CPU, GPU, QPU и будущими физическими backend'ами.
Архитектура v0.15Далее: x86-64 / UEFI P0
GitHubДокументация

Не ещё один клон Unix

Clearfold начинает не с Process/File, а с authority, изоляции и Computation. POSIX и другие исторические API могут существовать как compatibility layers, не диктуя устройство kernel.

Capabilities

Никаких неявных полномочий: authority выдаётся явно и может быть ограничена или отозвана.

User-space system

Драйверы, storage, network, GUI и policy находятся за границей микроядра.

Compute-native

Compute Graph и DataObject позволяют размещать работу на несхожих backend'ах, не маскируя QPU/GPU под CPU.

Ключевая идея

Универсальна система, которая строит систему

Meta-System инвентаризирует оборудование, разрешает зависимости и policy, а затем строит специализированный immutable Runtime.

Runtime должен быть малым и специализированным.
Универсальность и сложность живут в Meta-System, а не постоянно в работающем kernel.

Prototype P0

Первый прототип специально ограничен x86-64/UEFI и проверяет только фундамент: capability spaces, memory mapping, execution contexts, scheduler, IPC, notification/timer и user-space pager.
