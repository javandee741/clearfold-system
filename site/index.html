Not another Unix clone

Clearfold starts from authority, isolation and computation rather than historical process/file primitives. Compatibility layers may expose POSIX or other APIs without turning them into kernel foundations.

01

Capability-first

No ambient authority. Every privileged operation is backed by an explicit, attenuable capability.

02

User-space system

Drivers, storage, networking, GUI, policy and compatibility live outside the microkernel.

03

Compute-native

Computation graphs and DataObjects can be placed across unlike backends without pretending every accelerator is a CPU.

Runtime architecture

Small kernel. Explicit layers.

The kernel knows mechanisms: capabilities, memory mappings, execution, IPC, interrupts and time. High-level policy stays replaceable.

The universal part is not the running OS.
The Meta-System is universal; it constructs a specialized runtime for actual hardware and policy.

Prototype P0

Prove the foundation first

The first executable Clearfold will intentionally have no filesystem, network, USB, GPU or GUI. It exists to validate the capability microkernel model.
