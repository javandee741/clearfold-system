# Clearfold public identity

## Project name

**Clearfold**

Formal descriptor: **Clearfold — Heterogeneous Capability Computing System**.

Repository slug: **`clearfold-system`**.

Primary slogan: **Computation, not Process.**  
Secondary slogan: **The system that builds the system.**

## Naming rationale

The name **Clearfold** combines two ideas that match the architecture without trying to describe it literally:

- **clear** — explicit authority, inspectable composition, deterministic system construction and minimal hidden policy;
- **fold** — composition of hardware, policy, services and execution backends into a concrete runtime, as well as the familiar functional-programming idea of reducing a structure into a result.

The visual identity may use transparent layers, folded planes, branching paths and recomposition. Optical imagery can be used as a secondary motif for heterogeneous execution paths.
